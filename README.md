restaura el menu inicio de windows 11 a solo 6 iconos

v 0.3, 09- 2026

quita el nuevo menu de windows 11 conocido como new menu experience y restaura el menu original de windows 11

copia y pega este script en un bloc de notas y luego nombralo como un archivo .bat

o descarga el archivo .bat mas reciente

lo guardas la carpeta de vivetools de https://github.com/thebookisclosed

y ejecutas como administrador, reinicias windows, despues vas a panel de control, menu ( start ) y ya tienes las opciones de menu de inicio, pequeño y grande :-)
